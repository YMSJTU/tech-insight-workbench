# P0：搜索覆盖率、PDF 下载与图表保留

日期：2026-10-25。范围：先完成搜索/下载 P0，不引入多源会议目录、并发下载和 OCR。

## 1. 覆盖率指标

会议/期刊任务在 `result.coverage` 中记录：

- `source_total`：来源返回的原始记录数
- `non_paper_filtered`：版权页、委员会、Sponsors 等过滤数
- `expected_papers`：`source_total - non_paper_filtered`（目录未抓全时为估算）
- `discovered` / `selected`
- `truncated` / `ratio`

主题任务记录每个来源的 `queries / fetched / errors`，以及去重后的 `discovered / selected`。

归档完成后，父任务 `result.archive_stats` 汇总：

- `fulltext / abstract / metadata`
- `pdf_candidate_papers`：至少有一个 PDF 候选的论文数
- `download_attempts / download_success`
- `fulltext_yield`、`pdf_candidate_coverage`、`download_success_rate`

任务中心展示“发现 / 预期 / 覆盖率”和归档统计。

## 2. PDF 候选链

`backend/sources.py`：

- OpenAlex 返回所有 locations 的 `pdf_url`，并保留 arXiv ID。
- `static_pdf_candidates` 汇总候选并去重，顺序为发现记录来源 → arXiv 构造 URL。
- 静态候选耗尽后，`discover_pdf_candidates` 追加：
  - Unpaywall `url_for_pdf`（需 `UNPAYWALL_EMAIL`）
  - OpenAlex DOI 回查（非 OpenAlex 来源）
- 每篇最多尝试 `PDF_MAX_CANDIDATES` 个候选（默认 3）。

下载器 `fetch_pdf`：

- 校验公网地址、逐跳重定向、SNI/Host 保持。
- 检查 content-type 和 `%PDF-` 文件头，HTML/付费墙不落盘。
- 429/5xx 退避重试；403/404、非 PDF、超限、网络错误分别归类。
- 多 IP 尝试，限制 25 MB、30 秒；返回状态、content-type、字节数和尝试次数。

## 3. 下载尝试审计

新增 `download_attempts` 表：`paper_id / job_id / url / source / status_code / content_type / bytes / error_class / elapsed_ms`。

每次候选尝试写入一行；成功候选 `error_class` 为空。任务 result 同时保存候选数、尝试列表、成功标记和错误分类，便于按来源/错误类型统计。

## 4. PDF 解析与图表保留

`backend/parse_pdf.py` 改用 PyMuPDF：

- 正文：`page.get_text("text", sort=True)`，按阅读顺序输出。
- 表格：`page.find_tables()` 提取行，保存 `bbox`、`rows` 和 HTML。
- 图片：`page.get_images()` + `doc.extract_image()`，保存 PNG/JPEG 到 `data/files/<pdf>.assets/`。
- 版面：含图片、表格或矢量图（`get_drawings()`）的页面按 `PDF_RENDER_DPI`（默认 110）渲染 JPEG，保留图表视觉信息。
- 限制：300 页、200 万字符、40 MB 图片总量、每页最多 50 张图片/10 个表格。
- `Document.pages` 保存资源元数据；API `/api/documents/{id}/assets/{name}` 提供图片/版面；论文详情展示“原文版面、图片与表格”缩略图。
- 为避免 PyMuPDF 的布局提示污染 JSON stdout，解析期间在文件描述符层把 stdout 重定向到 stderr。

## 6. 已知边界

- 无线表格/复杂跨页表格可能漏检；扫描件仍需 OCR，暂未启用。
- PyMuPDF 为 AGPL/商业双许可；如需对外分发，应先确认许可证方案。
- Unpaywall 未配置 email 时不启用；出版社 landing page 的 `citation_pdf_url` 解析尚未加入（P1）。
- 下载仍串行，且每篇最多 3 个候选；更大批量需要 P2 的并发与限速。
- 覆盖率基线目前来自 OpenAlex 单源；P1 才做 Crossref/DBLP/出版社目录并集与缺口清单。

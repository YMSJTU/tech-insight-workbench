# 模块一：论文搜索详细设计

日期：2026-10-24。依赖模块二的 ArchiveService，不直接写技术与证据数据。

## 1. 输入与流程

POST /api/search 接收 topic（2–500 字）、sources（crossref/arxiv）、year_from/year_to、limit（1–20）、max_calls（0–40）。返回持久化父任务。默认 Crossref 与 arXiv，最多 5 篇自动归档，最多 16 次模型调用（搜索与归档共同计数）。

工作流：生成英文检索词 → 逐来源检索 → 规范化 → 精确去重 → 时间过滤 → 排序 → 保存候选与理由 → 对入选项创建独立归档子任务 → 汇总子任务终态。

模型可用且预算允许时生成不超过两个查询式。无模型时使用原始主题，明确 lexical 模式；中文原始词在英文来源召回有限，页面提示。模型规划失败时原始词回退并记录警告。

## 2. 来源适配器

| 来源 | 接口 | 输出与限制 |
| --- | --- | --- |
| Crossref | GET https://api.crossref.org/works；query.bibliographic、rows、filter | DOI、标题、作者、年份、venue、摘要、来源 URL、可选 PDF 链接 |
| arXiv | GET https://export.arxiv.org/api/query；search_query、max_results | Atom 解析，arXiv ID、标题、作者、摘要、日期、PDF 链接；请求间隔至少 3 秒 |

每来源最多抓取 limit×3（最高 60）项；不分页穷尽，不绕过访问限制。网络超时与来源异常分别记录，其他来源继续。只保存提供方真实返回的信息，摘要 HTML 标签去除。

官方接口依据：[Crossref REST 文档](https://github.com/CrossRef/rest-api-doc)、[arXiv API 手册](https://github.com/arXiv/arxiv-docs/blob/develop/source/help/api/user-manual.md)。提供方实际可达性需执行探测。

## 3. 候选规范化与排序

标准 Candidate：identity/title/doi/arxiv_id/authors/year/venue/url/pdf_url/abstract/source/query/rank/reason。DOI 转小写并去除 URL 前缀；arXiv 去版本后缀。精确身份相同跨来源合并，优先完整字段并保留 provenance 列表。不使用模糊标题自动归并。

先按用户年份硬过滤，再使用来源排名、题名/摘要词项重叠排序。理由明确表述为“来源排名 + 关键词匹配”，不谎称经过全文评估。模型负责查询规划，首版排序算法可解释且可复现。没有年份且用户指定范围时排除并统计。

最多 limit 个候选自动归档，无需再次审批。完整候选、入选标识、搜索词、来源错误、归档子任务 ID 保存在父任务 result 中。重复提交不会新增同一论文，但每次搜索保留自己的任务记录。

## 4. 与模块二协作

每个入选候选调用统一归档提交接口，parent_id 指向搜索任务。子任务独立持有文献输入，不跨父任务共享，因此父任务取消仅取消自己的子任务。数据库论文身份唯一约束负责数据去重。

子任务根据 pdf_url 尝试全文；下载失败降级摘要，并记录原因。PDF 是页面链接时不强行当作 PDF 解析。没有摘要且全文失败仅保存元数据，partial。

## 5. 预算与父任务状态

max_calls 是整次搜索的模型请求数上限。子任务读取根任务预算；数据库条件更新预留调用次数，超时请求也计数，防止并发穿透。任务 result 汇总 tokens（提供方未返回则不推算）。

父任务发现结束后进入 waiting，释放 Worker。Worker 在轮询时汇总：全部归档成功且无来源/预算警告为 succeeded；有部分成果但覆盖受损为 partial；无结果且所有来源失败为 failed；来源成功但零命中为 succeeded（空结果）；用户取消为 cancelled。

## 6. 页面与异常

搜索页提供主题、年份、来源、归档数和调用上限。提交后跳转任务中心并选中任务。任务详情提供查询词、入选论文、来源错误、逐篇归档状态及结果链接。外部调用失败显示可操作错误，不展示空白成功。

## 7. 验收

来源解析使用固定响应测试；跨来源同 DOI 去重；年份缺失处理；候选排序与上限；一个来源失败仍能继续；无结果成功；全部来源失败；父子任务预算共享与取消；搜索到知识库闭环。另执行少量真实来源联网探测，报告真实可达性，不以离线样例替代。

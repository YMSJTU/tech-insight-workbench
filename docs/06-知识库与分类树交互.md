# 知识库与分类树统一工作区

日期：2026-10-24。

## 页面变化

独立“分类管理”菜单合并到“技术知识库”。左侧展示技术域、问题域两棵树，右侧展示论文列表与来源筛选。Agent 分类建议折叠在论文列表下方。

- 点击箭头逐级展开或收起，支持任意层级及全部展开/收起。展开状态保存在当前浏览器，刷新或切换页面后保留。
- 点击分类名称筛选论文，选择上级时包含全部后代；技术域、问题域可交叉筛选。列表顶部显示完整分类路径，可单独清除。
- 点击节点右侧 `+` 新增子类；维度标题右侧 `+` 新增根分类。
- 点击铅笔编辑分类名称和父级。父级选择显示完整路径，不包含自身及其后代。
- 拖动节点到目标父节点会打开编辑框，检查并保存后完成移动。移动时整个子树与已有论文关联一起保留。
- 空分类可在编辑框内删除，需再次确认；有子类、论文或建议引用时拒绝删除，避免意外丢失关联。
- 论文详情新增“论文分类”：可同时勾选多个技术域和问题域节点，保存手动结果，或恢复 AI 分类。

## 数据与接口

- `POST /api/taxonomy`：新增节点。
- `PUT /api/taxonomy/{id}`：修改名称、父级；不允许跨维度移动。
- `DELETE /api/taxonomy/{id}?expected_version=...`：删除没有引用的空节点。
- 所有分类修改携带 `expected_version`，使用数据库事务锁与版本冲突检查。
- 层级校验拒绝自身父级、后代父级、同级同名、空名称和不同维度父级。
- `PUT /api/papers/{id}/categories`：保存人工分类；包含节点集合、论文分类修订号、分类树版本以及 manual 标记。
- 新增 `paper_categories` 表，仅用于用户覆盖；保留 AI 原始技术分类，重新分析不会覆盖人工选择。manual=false 时恢复使用最新 AI 结果。
- 知识库列表和筛选采用当前有效分类；技术详情仍显示模型对单个技术方案的分类证据。
- 表创建为增量操作，不重建现有表；初始分类骨架仅首次初始化时创建，用户修改或删除不会在重启时还原。
- Agent 提取期间如分类树变化，提交会被拒绝并提示重试，防止写入已经删除的节点。
